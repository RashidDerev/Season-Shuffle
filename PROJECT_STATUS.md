## Механика и сохранения

engine.js сохраняет текущую механику v8. SPACE сбрасывает средний ряд, стрелки вверх/вниз вращают барабан, влево/вправо сдвигают средний ряд. Подробные правила и запуск описаны в README.md. Не подменять их правилами из старых прототипов.

Сохранение текущей партии и настроек находится в localStorage браузера под ключом four-secrets-drum-v8; это не часть Git-репозитория.

## Проверка и продолжение

12 групп проверок tests/check.cjs прошли перед сохранением; atmosphere.js разбирается без ошибок. В последней визуальной итерации программно проверены плавное затухание, повторное появление, мобильный resize и остановка анимации при скрытии вкладки и сокращении движения.

Визуальная проверка через инструмент браузера не выполнена из-за недоступности browser access host. Следующий шаг при возвращении: открыть текущую игру на десктопе и телефоне, оценить композицию стрелок и орнамента, затем согласовать следующие узкие улучшения. Пользователь пока не выбрал новую задачу.

Запуск: npm start или node server.cjs, адрес http://127.0.0.1:4173/. Проверки: npm test. Зависимости и сборка не требуются. Все растры, исходные референсы, промпты и редактируемый код сохранены в репозитории. Подробные решения: assets/art-direction.md.
